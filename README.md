# 🔍 Basic Port Scanner

A simple Python script to scan open ports on a given IP address over a specified port range.

## 🚀 Features
- Scans any IP address
- Accepts custom port range
- Displays open ports
- Handles invalid input and interruptions

## 📦 Requirements
- Python 3.x

No external libraries needed.

## 🛠 Usage

```bash
python port_scanner.py <IP> <start_port> <end_port>
